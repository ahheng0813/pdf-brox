## Windows

1. Download **[PDF-BroX-Setup.exe](https://github.com/ahheng0813/pdf-brox/releases/latest/download/PDF-BroX-Setup.exe)** and open it.
2. If Windows shows *"Windows protected your PC"*, click **More info**, then **Run anyway**.
   The installer isn't code-signed yet, so Windows doesn't know it.
3. Follow the steps. No admin rights are needed.

To update, download and run the newest installer. It replaces the old version and
keeps your documents and settings. The app also tells you when a new version is out.

Can't run installers? Download **[PDF-BroX-Windows-portable.zip](https://github.com/ahheng0813/pdf-brox/releases/latest/download/PDF-BroX-Windows-portable.zip)**,
unzip it and run `pdf_editor.exe`.

Needs Windows 10 or 11 (64-bit).

Older versions are on the **[Releases](https://github.com/ahheng0813/pdf-brox/releases)** page.
